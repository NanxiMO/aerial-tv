长按 OK 键：移动时磁贴轻轻抖动，其他图标自动让位；不常用的 App 可以从主屏幕隐藏，随时在控制中心找回来。

壁纸

每天一张新风景，
或者你自己的照片。

每日精选跟随必应每日图片；内置的 8 组柔光渐变在电视上实时生成；我的照片用手机扫码就能传上来。

用手机设置

扫一下，
不用遥控器打字。

扫描壁纸面板上的二维码，手机上会打开一个原生风格的页面：上传照片、挑选壁纸、切换屏保。页面只在面板打开时开放，地址带随机令牌，同一网络里的其他设备猜不到。

开机就是它。
待机也赶不走。

国产电视大多只认自家桌面，还会在待机时清理第三方 App。Aerial 按「先温和、后强硬」的顺序处理，全程不需要 root，不卸载、不停用任何系统应用。

接管 HOME 键

先正常申请默认桌面；固件不让时，由桌面守护在系统之前接住 HOME 键，官方桌面一出现就把 Aerial 拉回来。

被杀后 0.5 秒复活

小米待机会强制停止所有第三方 App。系统随后会重新绑定 Aerial 的通知监听，Aerial 借此复活并重新打开守护。

断电重启也是它

开机后自动接管桌面。TCL 的「自启动管理」默认拦截第三方 App，安装脚本会帮你放行。小米、TCL 都实测过冷启动。

常见问题

    

      

        能不能打开网页就直接装到电视上？
        
目前做不到。浏览器不能直接连接电视的网络 ADB（网页没有原生 TCP），电视的 USB 口也不能作为设备被电脑连接，所以 WebUSB 这条路也走不通。最接近「一键」的方式，就是上面的 Agent 提示词和一行命令。

      

      

        会不会把电视弄坏？怎么还原？
        
不会卸载、停用或修改任何系统应用，只授予了几项权限、改了桌面和屏保设置。在「一行命令」里把 bash 换成 bash -s restore 运行，就会撤销所有授权和设置，回到原来的桌面；再加 --uninstall 会同时卸载 Aerial。

      

      

        需要哪些权限，用来做什么？
        
WRITE_SECURE_SETTINGS 用来在守护服务被系统关闭后重新打开它；通知监听用于被杀或开机后由系统拉起（不读取任何通知）；无障碍服务只用来接住 HOME 键，不读取屏幕内容；定位只用来显示 Wi-Fi 名称。

      

      

        航拍影片从哪里来？要多少流量？
        
影片由 Apple 的服务器直接播放，Aerial 只保存影片地址和地名。按 1080p H.264 播放，码率约 15–20 Mbps。连不上时会自动改用照片屏保。

      

      

        我的电视不在验证列表里，能用吗？
        
大概率可以。原生 Android TV / Google TV 最简单；国产固件按同样的思路处理。遇到问题欢迎在 GitHub 提 Issue，附上型号和安装脚本的输出。
